# Colibri LOOK

Сайт бутиков женской одежды в Краснодаре: главная, каталог с фильтрами, карточки вещей, образы, информация о бренде и контакты. Заказ через Telegram. Django 5.2 LTS, Python 3.12+, SQLite локально / MySQL на хостинге, серверные шаблоны и локальные шрифты, фотографии и видео.

## Локальный запуск

```sh
cd '/Users/den.kozarezov/Desktop/projects/colibri look'
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py seed_content
.venv/bin/python manage.py createsuperuser
.venv/bin/python manage.py runserver 127.0.0.1:8000
```

Сайт: http://127.0.0.1:8000/. Админка: http://127.0.0.1:8000/admin/.
В подготовленной локальной установке уже создан администратор; реквизиты находятся в `.admin-credentials.json` (файл исключён из Git, доступен только владельцу). На новой установке создайте свою учётную запись командой выше. Сменить пароль: `.venv/bin/python manage.py changepassword admin`.

`seed_content` добавляет 20 товаров, 6 категорий, 6 образов и 2 бутика с источниками. Команда идемпотентна и не переписывает правки редактора; повторный запуск может восстановить удалённые исходные записи с теми же slug, поэтому после передачи редактору запускать её не требуется.

## Обновление контента

1. Войти в `/admin/`.
2. **Товары → Добавить**: название, категория, цена, размеры через запятую, цвета, описание и главная фотография. Дополнительные фото — в блоке «Галерея товара». Поле «Видео MP4» принимает H.264/AAC до 40 МБ; на сайте появляется настоящий плеер. Основное фото служит обложкой. Разрешены JPEG, PNG, WebP до 8 МБ и 40 Мп.
3. Включить **Опубликовано**, чтобы вещь появилась на сайте. **На главной** добавляет её в подборку «Выбор Colibri»; показываются первые четыре по полю «Порядок».
4. **Наличие**: «Наличие уточняйте», «В наличии», «Предзаказ» или «Нет в наличии». Статус не вычисляется из остатков автоматически. Для снятия с сайта убрать «Опубликовано».
5. **Образы**: загрузить фото, написать текст и выбрать товары. Неопубликованные товары не показываются внутри образа.
6. **Главная и настройки сайта**: текст о бренде, фото и видео производства, соцсети и описание для поиска.
7. **Бутики**: адрес, телефон, часы, ссылка на карту и Telegram username консультанта (без `@`).

Для редактора можно создать отдельного сотрудника в «Пользователи»: активный, статус персонала, только нужные права на контент. Права управления пользователями ему не нужны.

Загружаемые фотографии хранятся в `media/`; исходные — в `static/images/`. Новая загруженная фотография заменяет исходную для отображения. Удаление новой фотографии возвращает исходное фото у импортированных товаров; для полностью нового товара показывается текстовое состояние без фото. Сделайте резервные копии БД и `media/` вместе.

```sh
.venv/bin/python manage.py makemigrations --check --dry-run
.venv/bin/python manage.py collectstatic --noinput
```

Покрываются публикация и скрытые категории, страницы товаров/образов, фильтры и поиск с кириллицей, цены, экранирование, пагинация, Telegram-черновик, валидация фото, права доступа, создание товара с фото в админке и повторное наполнение.

## Развёртывание

Настройки REG.RU, пути приложения и команды обслуживания описаны в [docs/deployment.md](docs/deployment.md). Для сервера экспортировать переменные из `.env.example`, задать длинный случайный `DJANGO_SECRET_KEY`, реальные домены и `DJANGO_DEBUG=0`. Файл `.env` не загружается автоматически; `DJANGO_ENV_FILE` позволяет указать приватный JSON-файл переменных вне публичной папки. В production сервер откажется запускаться без ключа.

Запуск приложения: `.venv/bin/gunicorn config.wsgi:application --bind 127.0.0.1:8000`. Статику после `collectstatic` обслуживает веб-сервер из `staticfiles/`, загрузки из `media/` — как неисполняемые файлы. Настроить HTTPS; при доверенном reverse proxy отдельно согласовать передачу и доверие `X-Forwarded-Proto`, иначе обязательный HTTPS-редирект нельзя корректно завершить. Django runserver только для локальной разработки.

Перед запуском на сервере выполнить `manage.py check --deploy` с production-переменными и проверить домен, доступ к медиа, резервное копирование и актуальность контактов. Данные SQLite подходят для небольшой редакции; если потребуется интенсивное одновременное редактирование, перенести БД на PostgreSQL.

## Переделка визуальной версии

Актуальная версия следует указанному пользователем [референсу Anvogue](https://bootstraptema.ru/_sf/67/6736.html): светлая витрина, шапка без верхней информационной полосы, слайдер с текстом и портретом, переключаемые подборки, категории, видеопримерки и компактный светлый подвал. Ручное переключение слайдов, swipe, клавиатура и reduced motion. Каталог и заказ через Telegram сохранены.

Образы с флажком «В сцене на главной» (до пяти, по полю порядка) управляют первым экраном. «Главная: основной кадр» заменяет портрет; для нового оформления загружайте PNG/WebP с прозрачным фоном. Поле второго кадра сохранено для совместимости, но больше не используется. Сильное увеличение `card_focus` отключено ради качества фото; поле сохранено для совместимости.

Девять видео восстановлены из скачанных MP4 720×1280 без перекодирования, с faststart. Фото пересохранены в WebP lossless без увеличения; публичный Telegram отдаёт большинство фото лишь 450×800. Галерея сохраняет исходные пропорции. В хиро используются отдельные прозрачные PNG после AI-удаления фона по запросу пользователя; сведения об обработке в `content/hero-cutouts.json`. На Retina ограничение исходников остаётся: для действительно высокой детализации нужны оригиналы заказчика. Загрузки через админку сохраняются без такого уменьшения. Воспроизводимый обработчик: `content/tools/prepare_media.py --source .qa/media` (через Python окружения); файл `content/media.json` хранит размеры и происхождение.

Источники теперь охватывают 63 публикации Telegram. Instagram по-прежнему не удалось получить: браузер возвращает HTTP-ошибку. Это открытое ограничение, а не выполненная часть сбора.

Новые решения и проверка: `docs/redesign-brief.md`, `docs/redesign-review.md`, `docs/verification.md`. Цены/медиа редактируются в админке. `content/catalog.json` — начальное наполнение для новых установок, а не замена правок администратора.
