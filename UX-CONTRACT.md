# Поведение

| Capability | Canonical owner | Source of truth | Allowed variants | Verification |
|---|---|---|---|---|
| Form | Django ModelForm / admin | модели и validators.py | create/edit | boutique.tests |
| CRUD | Django ModelAdmin | admin.py, Django permissions | Save, Save and continue | boutique.tests |
| Select/Listbox | native select | Django admin / catalog.html | platform popup | browser QA |
| Date | Django admin DateField | ru, Europe/Moscow | native Django widget | boutique.tests |
| Table Selection | Django admin actions | staff model permissions | explicit selected rows | boutique.tests |
| Toast | Django messages | Django admin | inline messages | admin save test |
| Scrollbar | site.css / admin.css | DESIGN.md tokens | visible system scrollbar | browser QA |

Каталог: GET-форма, запрос и фильтры в URL; пагинация сохраняет фильтры, невалидная страница возвращается к допустимой. Скрытые товары/категории/образы не доступны по прямой ссылке. Карточка: галерея, достоверные размеры, цена и дата её источника, обращение в выбранный бутик. В Telegram передаётся название товара и выбранный размер как черновик, отправляет сам посетитель.

CMS: русские подписи, серверная валидация, только staff с разрешениями; удаление требует стандартного подтверждения Django; публикация отдельным флагом. Фотографии: JPEG/PNG/WebP до 8 МБ и 40 Мп, проверяются Pillow. Видео: MP4 до 40 МБ, проверяются расширение, размер и сигнатура контейнера; для браузеров редактор загружает H.264/AAC. SVG не принимается. Сохранение штатно возвращает в список, дополнительная кнопка оставляет форму открытой.


Главная: до пяти опубликованных образов с `on_home`, порядок из админки. Хиро по референсу Anvogue: текст слева, прозрачный силуэт модели справа на едином светлом фоне; основной кадр управляется полем `hero_image` (PNG/WebP с альфа-каналом). Сохранившееся поле `hero_detail` зарезервировано и в текущем хиро не отображается. Управление стрелками, точками, клавиатурой и горизонтальным жестом. Без автосмены и перехвата прокрутки. Неактивные истории inert и aria-hidden, смена объявляется через aria-live. Reduced motion отключает анимацию.

Подборки главной: ссылки с GET-параметром `collection`, сервер выбирает нужную панель. JS переключает панели без перезагрузки и сохраняет выбор в URL; Back восстанавливает предыдущую подборку. Неизвестный ключ показывает «Выбор Colibri». Только опубликованные вещи активных категорий. Категории открывают отфильтрованный каталог. Видеопримерки включают опубликованные образы с загруженным либо исходным видео.

Видео: нативные controls и явное нажатие Play, preload=none. Вне экрана и при скрытой вкладке воспроизведение останавливается. Открытие следующего ролика останавливает предыдущий. Видео в хиро не используется: на первом экране настоящие фото, ролики доступны в образах, карточках и блоке производства.

Товар: одна горизонтальная лента фото и видео, scroll-snap, свайп, стрелки, счётчик, ссылка на видеокадр; на телефоне дополнительные фото не отодвигают информацию и заказ вниз. Неактивный ролик останавливается. Для парфюмерии выбор обозначается как «Объём» и так же передаётся в Telegram. Цена карточки аромата № 5 относится к 10 мл; цены остальных объёмов приведены в описании, авторасчёта нет.

Без JavaScript: главные образы доступны последовательно, видео с нативными controls; галерея прокручивается, ссылки и GET-формы работают. JS добавляет переключение и приостановку, а не доступ к содержимому.
