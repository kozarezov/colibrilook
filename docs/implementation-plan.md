# Colibri LOOK — план реализации

Цель: локально работающий Django-сайт с реальным контентом и CMS. Спецификация: PRODUCT.md, DESIGN.md, UX-CONTRACT.md, content/RESEARCH.md. Работа в существующей main; без push, новых веток и публикации.

- [x] Скелет Django и проверки публичных маршрутов: `config/`, `boutique/tests.py`. Убедиться в падении отсутствующих главной и каталога.
- [x] Модели `Category`, `Product`, `ProductImage`, `Look`, `Store`, `SiteSettings`; публикация, изображения и размеры; миграции, русская админка, валидация. Проверки скрытого контента, прав и загрузки.
- [x] Каталог: поиск, категории, размеры, сортировка и пагинация; карточка с галереей и Telegram. Главная и информация о бутиках из CMS.
- [x] Идемпотентная команда `seed_content`, исходные цены/размеры, локальные фото, источники. Повторная команда не перезаписывает правки редактора.
- [x] Дизайн: крупный Colibri LOOK, реальные фото, адаптивные шаблоны и CSS, доступные состояния и reduced motion.
- [x] Проверки Django, collectstatic, браузер 1440/768/390, каталог/карточка/админка, документация запуска и редактирования.

Review focus: скрытый контент по прямому URL; отрицательные цены/поддельные картинки; пустой каталог и некорректные параметры; длинные русские названия; повторное наполнение после правок редактора. Финальная проверка не отправляет сообщения в Telegram и не публикует сайт.
