## Дизайн-детекторы

Taste Skill lint и browser inspect запущены. Инспектор не нашёл горизонтального переполнения, сломанных фото, ошибок JavaScript или недостаточного цветового контраста. Его строгие стилистические правила не проходят для подписи над хиро, тени активной вкладки, разделителя подвала и компактных размеров текста. Эти элементы оставлены по явному референсу Anvogue и задокументированы, отчёт не объявляется полностью зелёным. Предупреждение still-page относится к отсутствию автоматического движения при скролле: анимация смены слайда запускается действием пользователя и проверена отдельно, ролики запускаются вручную. Горизонтальная лента видео на телефоне — намеренный scroll-snap с видимой следующей карточкой. Полный отчёт: `.taste-skill/inspect/report.json`.
