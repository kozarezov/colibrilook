# Colibri GitHub Actions deployment plan

Goal: pushes to main run checks and deploy to the existing REG.RU account without replacing editorial data or exposing secrets.

Architecture: GitHub Actions checks on PR/main, deployment only on main after checks. Server release artifacts live inside the existing application directory; no repository clones or worktrees. A shared private configuration and media directory survive deployments. Passenger resolves an atomic current symlink. Pre-migration database backup, isolated dependencies per release, application/DB health check, automatic code rollback on failed activation; schema rollback remains manual because MySQL migrations are not transactional.
